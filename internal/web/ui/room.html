        Personas

        Each persona is an AI with its own Claude session. Changes apply from its next answer.

        Answers the personas start one after another (every N answers, or when an answer names another persona) before they pause. A message from a person starts the count over.

        Each one in its own sandbox on the AI host's computer. When two edit the same document, the second runs again on the new version. Only the AI host switches it.

        Room skills

        The room's own copies of skills, at the version copied. They stay when whoever copied them leaves, and any persona can turn them on.
