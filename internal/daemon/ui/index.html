        Unsigned binaries

        Off by default. While on, the instance's worker runs whatever binary it serves, signed or not: for testing local builds only. To switch it on, type the instance's host exactly as in its URL.

        Trusted dev keys

        Worker binaries signed with one of these cosign public keys run like project releases. Keys also load from the dev-keys folder of the supervisor's config.
